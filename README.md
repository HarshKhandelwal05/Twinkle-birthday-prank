# Birthday Prank Page 🦉😂
1. Open `config.js` and set her name and your name.
2. (Optional) Funny GIFs: paste direct .gif links in `gifs:[...]` inside config.js, OR put files named 1.gif, 2.gif ... 8.gif inside the `gifs` folder.
3. Test: double-click `index.html`.
4. Deploy: push the files to GitHub (index.html must be at the repo's top level) and publish with Render Static Site, Publish Directory = `.`
